\begin{frame}
\frametitle{Notaci\'on}
$m^{f,D}_{ij}$ = $|$$\{d \in D $ $|$ $f(d_{1})=j \land d_{2}=i\}$$|$ \\
\vspace{3mm}
\begin{itemize}
\item $i$ es la clase real
\item $j$ es la clase que predice el modelo f
% \item Las clases ser\'an reemplazadas por su nombre
% \item Los valores ij ser\'an reemplazados por el nombre de la confusi\'on
\item $D$ es el dataset utilizado, conteniendo un conjunto de pares $d_1$ instancia, $d_2$ clase real asociada, y su valor por defecto que representa todos los datos disponibles es $D$
\item $f$ es el modelo usado y puede valer:\\
\begin{itemize}
\item $M$ como el modelo a analizar\\
\item $S_{M}$ como el sistema compuesto con el modelo M\\
\item $S_{*\rightarrow x}$ como el sistema intervenido, donde el componente es la funci\'on de clasificaci\'on constante que devuelve la clase $x$
\end{itemize}
\end{itemize}
\end{frame}

\begin{frame}
\frametitle{Especificaci\'on del problema}
La peor es la que maximiza: \\
\vspace{3mm}
\begin{itemize}
\item {$\STP$ * $\SCTP$ + $\SFN$ * $\SCFN$ + 

$\SFP$ * $\SCFP$ + $\STN$ * $\SCTN$}
\end{itemize}
\vspace{3mm}
Como los costos asociados a las confusiones de aciertos valen 0 y las de los fallos 1, es equivalente a maximizar: \\
\vspace{3mm}
\begin{itemize}
\item $\SFN$ + $\SFP$
\end{itemize}
\vspace{3mm}
El an\'alisis tambi\'en vale para otros casos.
\end{frame}
