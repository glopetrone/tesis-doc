\begin{frame}
\frametitle{Introducci\'on}
Para resolver un probema de clasificaci\'on, se tiene un sistema compuesto con distintos modelos componentes en paralelo y un fusionador. Cada uno de esos modelos mira features de los datos y devuelve una clase. Luego se fusionan sus resultados mediante alg\'un m\'etodo, resultando en que el sistema determina la clase del dato de forma un\'ivoca. \\
\vspace{3mm}
Particularmente, el sistema resuelve problemas de clasificaci\'on binaria.
\end{frame}

\begin{frame}
\frametitle{Intervenci\'on}
Se va a utilizar una operaci\'on sobre el sistema llamada intervenci\'on, basada en la intervenci\'on de las redes bayesianas. \\
\vspace{3mm}
Al sistema incompleto, en el lugar del modelo se le inserta una funci\'on de clasificaci\'on constante. Esta funci\'on ignora el dato de entrada y devuelve siempre el mismso resultado de clasificaci\'on.
\end{frame}



\begin{frame}
\frametitle{Intervenci\'on}
Los dos casos de intervenci\'on que ser\'an usados son la evaluaci\'on del sistema con un componente que devuelve siempre Positive y con uno que devuelve siempre Negative. \\
\vspace{3mm}
Luego se podr\'ian calcular las matrices de confusi\'on asociadas a sus resultados.
\end{frame}

\begin{frame}
\frametitle{Costo en peor caso}
\begin{itemize}
\item La m\'etrica a evaluar va a ser, dado un sistema y dado un potencial modelo componente, calcular una cota al costo del sistema, es decir, el peor caso del sistema dado que tenga a ese modelo como componente.
\end{itemize}
\end{frame}



\begin{frame}
\frametitle{Motivaci\'on}
Un posible caso de uso de esta funci\'on de costo puede ser realizar b\'usqueda de hiperpar\'ametros. \\
\vspace{3mm}
Otro posible uso puede ser la posibilidad de encargar el desarrollo del modelo componente a un tercero, sin la necesidad de darle todo el sistema para evaluarlo.
\end{frame}

\begin{frame}
\frametitle{Etapas de la evaluaci\'on}
Para poder comparar entre modelos se separa el proceso en dos partes:\\
\vspace{3mm}
\begin{itemize}
\item Primero es evaluado el sistema sin el modelo, usando la intervenci\'on. Se registran las probabilidades de acierto en el sistema intervenido con un modelo que da siempre positive, y uno que da siempre negative.
\item Luego usando esos valores, se ejecuta el modelo de forma independiente para calcular alguna funci\'on de costo asociada.
\end{itemize}
\end{frame}
